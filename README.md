# State-Space Search Toolkit

Post-course portfolio curation of state-space search work from CSE 415. This repository presents the implementation as a small reusable Python toolkit rather than a raw assignment export.

## What is included

- Breadth-first search for unweighted state spaces.
- A* search with pluggable successor, goal, cost, and heuristic functions.
- Small demo problems for the river-crossing puzzle and 8-puzzle heuristics.

Course starter files, reports, logs, assessment artifacts, and private course materials are intentionally not bundled.

## Run

```powershell
python demo.py
```

No external Python packages are required.
