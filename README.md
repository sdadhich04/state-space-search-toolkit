# State-Space Search Toolkit

Post-course portfolio curation of state-space search work from CSE 415. This repository presents the implementation as a small reusable Python toolkit rather than a raw assignment export.

The toolkit provides graph-search breadth-first search for unweighted state spaces and A* search with configurable successor, goal, step-cost, and heuristic functions. Included examples cover the river-crossing puzzle and 8-puzzle search.

## Hardware, tools, and libraries

- No hardware is required.
- The project runs as a command-line Python program; no package installation or build system is required.
- It uses Python 3.10 or newer and only Python's standard library. No third-party libraries are required.

## Run

From the repository root:

```powershell
python demo.py
```

The demo runs BFS on the river-crossing example and A* on the 8-puzzle example, then prints each path and search statistics.
